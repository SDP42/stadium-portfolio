# Scout mode

Visitors earn XP for exploring and unlock badges. Progress is kept in the visitor's own browser (`localStorage`, key `sdp42fc.scout.v1`) and can be reset from the badge cabinet; the site works the same without it.

## XP

| Action | XP |
|---|---|
| First visit to a zone | 10 |
| Scouting a project for the first time | 25 |
| Scoring a penalty | 30 |
| Unlocking a badge | 50 |

## Levels

| Level | From |
|---|---|
| Academy | 0 XP |
| Reserves | 150 XP |
| First team | 400 XP |
| Captain | 800 XP |
| Club legend | 1,300 XP |

## Penalty shootout

Five kicks against the BUGS FC keeper at `#/penalty`. Aim with the mouse (or tap) inside the goal and click or press Space. The best score is saved with the rest of the visitor's progress.
